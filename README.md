# IPTV-Italia
Questa repository contiene link ai principali canali TV nazionali e regionali e alle radio italiane, raccolti in tre file M3U da aprire con un qualsiasi programma che supporti file playlist. I link provengono da stream ufficiali; la disponibilità può dipendere dalle restrizioni geografiche dei broadcaster. Intendo aggiornare i link non funzionanti o aggiungere nuovi canali se vedo commenti che lo chiedono ed è nelle mie capacità farlo legalmente.

This repository contains links to Italian national and regional TV channels and radio stations in three M3U playlist files. The links are taken from official streams and may be subject to geographic restrictions. I intend to update broken links or add channels when I can verify an official source.

# Come usarla
Incolla l'URL **Raw** della playlist nel tuo player IPTV oppure scarica il file e importalo. Questi link puntano a questa fork, quindi includono anche le modifiche locali (come RTP Messina).

| Playlist | URL Raw |
|:--|:--|
| TV base | https://raw.githubusercontent.com/albertomercurio/IPTV-Italia/main/iptvita.m3u |
| TV con loghi e gruppi | https://raw.githubusercontent.com/albertomercurio/IPTV-Italia/main/iptvitaplus.m3u |
| Radio | https://raw.githubusercontent.com/albertomercurio/IPTV-Italia/main/ipradioita.m3u |

Non usare la pagina GitHub con `/blob/`: il player deve scaricare direttamente il file M3U.

**iptvitaplus.m3u** contiene i canali TV, i loghi, i gruppi e i numeri canale; non include una guida programmi XMLTV/EPG.

For the original project and its releases, see [Tundrak/IPTV-Italia](https://github.com/Tundrak/IPTV-Italia). The playlist URLs above point to this fork.

**RTP Messina:** RTP is listed as channel 19. If its direct stream does not play, the broadcaster's official web player is [player.gazzettadelsud.it/rtp](https://player.gazzettadelsud.it/rtp). That web page is a fallback for browser viewing, not a replacement M3U stream URL.

## Problemi noti
- VLC e tutti i player basati su di esso (come Fermata Auto per Android) potrebbero avere problemi nel riprodurre i canali (si sconsiglia l'uso di VLC e surrogati in generale per la visione della lista)
- I numeri LCN dei canali regionali non sono accurati, perchè i canali regionali cambiano numero spesso anche tra provincia e provincia

## Verificare le playlist

Esegui questi controlli dalla cartella principale del repository:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/validate_playlists.py
```

Il validatore controlla la struttura M3U e segnala gli URL firmati con una scadenza esplicita già passata. Non prova a riprodurre gli stream: la disponibilità può dipendere da posizione, restrizioni del broadcaster, intestazioni HTTP, codec o cambiamenti della fonte. Un avviso di scadenza invita a controllare il link, ma non dimostra da solo che il canale sia irraggiungibile. GitHub Actions esegue gli stessi controlli quando cambiano le playlist o i file di validazione.

# Segnala problemi e chiedi nuovi canali
Se un qualsiasi link a un canale TV o radio non funzionasse, basta segnalarmelo aprendo un'Issue da [**questo**](https://github.com/Tundrak/IPTV-Italia/issues/new?labels=Problema&template=problema-canale.md&title=%5BProblema%5D) link (ricorda prima di controllare se qualcun altro ha già creato un'Issue con un problema simile o se il problema è già conosciuto guardando nella sezione "Problemi Noti" o nelle note delle release).  
Inoltre, accetto richieste per nuovi canali TV o radio nazionali (soprattutto i "grandi assenti" di cui sopra), se li posso aggiungere da fonti ufficiali. Basta aprire un'Issue da [**questo**](https://github.com/Tundrak/IPTV-Italia/issues/new?labels=Richiesta+canale&template=richiesta-canale.md&title=%5BRichiesta+Canale%5D) link.
